## 1. Обновлённый текст объявления (OLX и соцсети)

**Заголовок:** CapCut-монтажёр / креатор для TikTok и Reels — VBR Music

**Текст:**

Ищем несколько CapCut-монтажёров для создания коротких видео в TikTok и Reels.

Главное — понимать актуальные тренды, уметь придумывать идеи и собирать динамичные ролики в CapCut. Большой профессиональный опыт не требуется: подойдут студенты, начинающие монтажёры и те, кто делает эдиты для себя или занимается этим как хобби.

Что нужно делать:
— искать и предлагать идеи для роликов;
— следить за трендами TikTok и Reels;
— монтировать короткие видео в CapCut;
— ответственно выполнять задачи в оговорённые сроки.

Что для нас важно:
— базовое владение CapCut;
— понимание трендов и формата коротких видео;
— чувство ритма и насмотренность;
— ответственность и готовность быть на связи.

Свой TikTok-аккаунт или примеры работ будут плюсом.

**Оплата:** сдельная, платим сразу за результат, выплаты раз в неделю (не помесячно). В среднем наши монтажёры получают от 200 000 до 500 000 тенге в месяц при средней загруженности.

В первую очередь рассматриваем кандидатов из Алматы — у нас есть офис, где можно работать и придумывать идеи вместе с командой. Кандидаты из других городов тоже могут работать удалённо.

Чтобы откликнуться, перейди в Telegram-бота, заполни короткую анкету и выполни небольшое тестовое задание.

👉 [ссылка на бота]

### 2.6 Отправка результата

Бот принимает **либо** видеофайл, **либо** ссылку на TikTok:

- Если пришёл видеофайл → бот пересылает его как есть в админ-группу (файл нигде не сохраняется на сервере, только пересылка сообщением), сохраняет в Notion статус + факт отправки.
- Если пришла ссылка на TikTok → бот сохраняет ссылку в Notion, в админ-группу уходит карточка со ссылкой (и превью, если Telegram его подтягивает).
- Если прислано что-то другое (фото, документ, текст) → бот просит прислать видео или ссылку на TikTok ещё раз.

После получения:

Кнопки: `Подтвердить отправку` / `Заменить видео`

### 2.7 Напоминание через 24 часа (только если тестовое начато, но не отправлено)

> Привет! Напоминаем о тестовом задании 👋
>
> С момента начала прошли сутки. Когда работа будет готова — пришли видео или ссылку на TikTok прямо сюда.

Кнопки: `Отправить готовое видео` / `Посмотреть задание`

*(Второе напоминание через 48 часов — опционально, нейтральный тон, без давления)*

### 2.8 После подтверждения отправки

> Готово! Мы получили твоё тестовое задание ✅
>
> Посмотрим работу в течение **3 рабочих дней**.
>
> Если всё понравится — напишем тебе лично в Telegram. Если сообщения не будет в течение этого срока, значит на этом этапе мы продолжили с другими кандидатами.

### 2.9 Решение «Берём»

> Всё супер! Нам понравилось твоё тестовое задание 🙌
>
> Мы хотим продолжить общение и обсудить дальнейшую работу.
>
> Жди сообщение в личку в Telegram — скоро с тобой свяжется наша команда.

### 2.10 Решения «В резерв» / «Не берём»

Кандидату сообщение не отправляется — меняется только внутренний статус в Notion (см. п.2.2, кулдаун 2 недели).

### 2.11 Частые вопросы (FAQ)

**Какой формат/длительность видео нужны?**
Жёстких требований нет — команда сама оценит, подходит эдит или нет.

**Какой звук использовать?**
Только звук, который дан в задании. Звук из визуальных референсов использовать нельзя.

**Где брать материалы?**
Подбираешь самостоятельно, если отдельно не сказано иное.

**Обязательно ли копировать референс?**
Нет, референсы — это направление по стилю и динамике, не покадровая копия.

**Можно ли использовать шаблон CapCut?**
Да, можно.

**Куда отправлять готовое видео?**
Видеофайлом прямо в этот бот или ссылкой на опубликованный TikTok с эдитом.

**Что если видео не отправляется из-за размера?**
Пришли ссылкой на TikTok — это даже более предпочтительный вариант.

**Когда будет ответ?**
В течение 3 рабочих дней после отправки. Если тестовое подойдёт — напишем лично.

**Как оплата?**
Работа сдельная, оплата сразу за результат, выплаты раз в неделю. Точные условия обсуждаются лично после успешного тестового.

**Можно ли связаться с администратором?**
Для нестандартных технических проблем — да, здесь: @doreus.

## 3. Карта состояний бота

```
START
  │
  ▼
[проверка Telegram ID в базе]
  │
  ├─ новый кандидат ──────────────► ANKETA_NOT_STARTED
  ├─ анкета не закончена ─────────► ANKETA_IN_PROGRESS (продолжить с шага)
  ├─ тест начат, не отправлен ────► TEST_STARTED
  ├─ отправлено, на проверке ─────► PENDING_REVIEW
  ├─ отклонён, < 2 недель ────────► REJECTED_COOLDOWN
  ├─ отклонён, ≥ 2 недель ────────► REJECTED_RETRY_OFFERED
  ├─ в резерве ────────────────────► RESERVED
  └─ принят ────────────────────────► ACCEPTED

ANKETA_NOT_STARTED → (кнопка) → ANKETA_IN_PROGRESS
ANKETA_IN_PROGRESS → (7 вопросов заполнены) → ANKETA_DONE
ANKETA_DONE → (показ тестового) → TEST_EXPLAINED
TEST_EXPLAINED → (кнопка "Начать тестовое") → TEST_STARTED [старт таймера 48ч]
TEST_STARTED → (24ч) → REMINDER_SENT (не меняет статус, просто флаг)
TEST_STARTED → (видео или TikTok-ссылка получены) → DRAFT_RECEIVED
DRAFT_RECEIVED → (Подтвердить отправку) → SUBMITTED → карточка в админ-группу
DRAFT_RECEIVED → (Заменить видео) → TEST_STARTED (ждём новый файл/ссылку)
SUBMITTED → PENDING_REVIEW

PENDING_REVIEW → (админ: Берём) → ACCEPTED → сообщение кандидату
PENDING_REVIEW → (админ: В резерв) → RESERVED → без сообщения
PENDING_REVIEW → (админ: Не берём) → REJECTED_COOLDOWN → без сообщения [таймер 2 недели]

REJECTED_COOLDOWN → (2 недели прошло) → REJECTED_RETRY_OFFERED
REJECTED_RETRY_OFFERED → (кандидат зашёл в бота) → новое тестовое (другой референс/звук) → TEST_EXPLAINED
```

**Статусы (Select "Статус"):**
Открыл бота → Начал анкету → Заполнил анкету → Посмотрел тестовое → Начал тестовое → Получил напоминание → Черновик получен → Отправлено, ожидает проверки → Принят → В резерве → Не прошёл (кулдаун) → Не прошёл (можно повторно) → Приглашён в офис → Назначен созвон → Начал работу → Не вышел → Завершил сотрудничество

**Виды (views):**
- "Ожидают проверки" — фильтр по статусу, для команды
- "Резерв" — для быстрого пополнения при текучке
- "Алматы + готовы приехать" — приоритетная выборка
- "По источникам" — группировка для аналитики, откуда приходят лучшие кандидаты

## 6. Технический стек для v1 (бесплатно / почти бесплатно)

- Бот: Python (aiogram) или Node (grammY/telegraf) — бесплатно
- Хостинг: бесплатный tier VPS/PaaS (например Railway/Render free tier, или недорогой VPS $4–5/мес если бесплатного окажется мало для аптайма)
- База данных кандидатов: **Notion** через API (без отдельной БД для MVP — упрощает п.21 требований)
- Хранение видео: не храним — либо пересылка сообщением в Telegram-группу, либо ссылка на TikTok в Notion
- Напоминания: встроенный планировщик задач в самом боте (APScheduler / node-cron), без внешних сервисов
- Резервное копирование: Notion уже хранит историю; дополнительно можно включить экспорт БД раз в неделю
