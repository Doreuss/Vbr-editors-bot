# VBR Editors Bot

Telegram-бот для автоматизированной воронки поиска CapCut-монтажёров/креаторов
для VBR Music. Полная логика описана в `SPEC.md` (копия из чата).

## Что делает бот

1. Приветствует кандидата от лица VBR Music, объясняет, что мы формируем
   большую команду монтажёров.
2. Собирает короткую анкету.
3. Показывает тестовое задание (референсы + обязательный звук).
4. Через 24 часа шлёт одно напоминание, если тестовое не отправлено.
5. Принимает результат — видеофайл (пересылается в админ-группу без
   локального хранения) или ссылку на TikTok.
6. Кладёт карточку кандидата в закрытую админ-группу с кнопками
   `✅ Берём` / `🟡 В резерв` / `❌ Не берём`.
7. Пишет кандидату **только если его взяли**. Отказ и резерв — полная тишина,
   без каких-либо сообщений. При повторном заходе в бота статус не
   раскрывается: кандидат видит нейтральное "на рассмотрении" (если < 2 недель)
   либо предложение новой задачи (если ≥ 2 недель — кулдаун истёк).
8. Все кандидаты и статусы сохраняются в Notion (см. `NOTION_DATABASE_ID`).

## Стек

- Python 3.11+
- [aiogram 3.x](https://docs.aiogram.dev/) — Telegram Bot API
- [APScheduler](https://apscheduler.readthedocs.io/) — напоминания через 24ч и
  автопроверка кулдауна
- Notion API (через официальный `notion-client` пакет) — хранение кандидатов
- SQLite (`state.db`) — только служебное хранение FSM-состояний aiogram,
  видео нигде не хранится файлом

## Установка

```bash
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

Заполните `.env`:

```
BOT_TOKEN=          # получить у @BotFather
ADMIN_GROUP_ID=     # ID закрытой группы для карточек кандидатов
ADMIN_USER_IDS=     # через запятую, Telegram ID админов (сейчас: @doreus)
NOTION_TOKEN=       # Notion internal integration token
NOTION_DATABASE_ID= # ID базы "VBR Editors — Кандидаты"
```

### Как получить BOT_TOKEN

1. Написать @BotFather в Telegram → `/newbot`
2. Имя: `VBR Editors Team` (или похожее)
3. Username: `VBR_Editors_bot` (проверить свободен ли, при занятости —
   `VBR_Editors_team_bot` и т.п.)
4. Скопировать выданный токен в `.env`

### Как получить ADMIN_GROUP_ID

1. Создать закрытую Telegram-группу, добавить туда бота как админа
2. Отправить любое сообщение в группу
3. Открыть `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates` в браузере —
   в ответе будет `chat.id` группы (отрицательное число)

### Как получить NOTION_TOKEN

1. https://www.notion.so/my-integrations → New integration
2. Скопировать Internal Integration Token
3. В самой базе "VBR Editors — Кандидаты" → `...` → Connections → подключить
   созданную интеграцию

## Запуск

```bash
python -m bot.main
```

## Деплой

Для продакшена — любой VPS с Python 3.11+ и systemd/pm2 для автозапуска,
либо Railway/Render (free tier). Бот работает через long polling, вебхук не
обязателен для старта.

## Структура

```
bot/
  main.py                 — точка входа, регистрация роутеров
  config.py                — переменные окружения
  notion_client.py         — все операции с Notion (создание/обновление кандидата)
  states.py                — FSM-состояния анкеты и тестового
  texts.py                 — все тексты бота в одном месте (легко редактировать)
  scheduler.py              — напоминание через 24ч, автопроверка кулдауна
  handlers/
    start.py                — /start, определение статуса кандидата, анкета
    test_task.py             — показ тестового, приём видео/ссылки
    admin.py                 — карточка в админ-группе, кнопки решения
```

## Важно про приватность отказа

Согласно требованиям VBR Music: кандидату **никогда** не сообщается об
отказе явно. Вся логика "рассмотрения" и "новой задачи после кулдауна"
реализована в `handlers/start.py::handle_returning_candidate` — там же
единственное место, где стоит эта бизнес-логика. Если понадобится что-то
поменять — сначала обсуждаем в чате с Claude, затем правим этот файл.
